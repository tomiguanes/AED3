# AED3
Repositorio colaborativo para subir, compartir y resolver ejercicios prácticos de la materia "Algoritmos y Estructura de Datos III", cursada en el Instituto Juan XXIII.

Este espacio tiene como fin:

Practicar la programación en Python.
Practicar el uso de control de versiones en GitHub y repositorios grupales.
Compartir resoluciones individuales o grupales de los trabajos prácticos.
Aprender juntos y mejorar nuestras habilidades.

¿Dónde ver y subir las resoluciones?
La idea es que cada colaborador vaya subiendo sus resoluciones a su propia rama.
